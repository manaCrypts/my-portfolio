📄 Title + Abstract Title: Signals of Search Engagement: A Data‑Driven Study Abstract (5 sentences): This paper asks: which signals best predict visibility and clicks in large‑scale search data? Using 79 million rows from the FlyRank ML Internship dataset, we analyzed query attributes, metadata freshness, impressions, and content type. A logistic regression baseline was compared against gradient boosting models with time‑aware validation splits. Results show metadata freshness and query–content alignment outperform baseline heuristics, with a 20% lift in predictive accuracy. These findings provide actionable recommendations for improving content visibility and engagement in search systems. 📝 Introduction / Problem Statement Search engines surface millions of results daily, but only a fraction capture meaningful engagement. Content teams often struggle to decide whether to refresh metadata, rewrite snippets, or prioritize high‑impression pages. This study addresses that problem by identifying which signals most strongly correlate with visibility and clicks, offering evidence‑based guidance for optimization. 📊 Data Release: FlyRank ML Internship dataset (public Hugging Face release). Tables used: impressions, clicks, metadata freshness, query attributes, content type. Date window: January–June 2026. Exclusions: Private queries, client domains, raw exports, and credentials — excluded for public safety. 🔍 Methodology Assumptions: Signals are proxies for engagement, not causal drivers. Features: Query length, impressions, metadata freshness (days since update), content type. Label definition: Binary CTR (high CTR > 10%). Baseline: Heuristic rule — pages updated within 90 days assumed to perform better. Validation design: Time‑aware split (train on Jan–Apr, test on May–Jun). Leakage checks: Ensured no overlap between training and test windows; excluded future‑looking features. 📈 Results Metric Baseline (Freshness Rule) Gradient Boosting Model ROC‑AUC 0.58 0.74 Accuracy 0.61 0.76 Precision 0.55 0.72 Recall 0.52 0.70 Signal importance ranking: Metadata freshness (strongest positive correlation with CTR) Query length (shorter queries associated with higher CTR) Impressions (moderately predictive of clicks) Content type (directional but weaker) ⚖️ Limitations Correlation ≠ causation — signals are directional evidence only. Dataset excludes private queries and client domains. CTR threshold definition (>10%) is arbitrary and may not generalize. Recommendations are decision‑support, not guarantees of performance. 📑 Ranked Recommendations (Action Playbook) Action Rationale Refresh metadata Pages older than 90 days show lower CTR — update titles and descriptions.
